# Bank Loan Analysis Dashboard

An interactive Power BI dashboard developed to analyze bank loan performance, portfolio trends, and loan quality using financial loan data.

## 📌 Project Overview

This project focuses on analyzing loan applications, funded amounts, repayments, interest rates, and loan quality to provide a comprehensive view of lending performance.

The dashboard is divided into three sections:

- **Highlights** – Key KPIs, MTD/MoM performance, and Good vs. Bad Loan analysis
- **Overview** – Trends and portfolio analysis by month, state, purpose, term, employee length, and home ownership
- **Details** – Detailed loan-level information with interactive filtering

## 📊 Key Insights

- Total Loan Applications and Funded Amount
- Total Amount Received
- Average Interest Rate
- MTD and MoM Performance
- Good vs. Bad Loan Analysis
- State-wise Loan Distribution
- Loan Purpose and Term Analysis
- Borrower Profile Analysis

## 🛠️ Tools & Technologies

- **SQL** – Data querying and analysis
- **Power Query** – Data cleaning and transformation
- **Power BI** – Data modeling and visualization
- **DAX** – Measures and KPI calculations

## 🎯 Key Features

- Interactive slicers for State, Grade, Purpose, and Good vs. Bad Loan
- KPI cards with MTD and MoM comparisons
- Interactive charts and portfolio segmentation
- Detailed loan-level analysis
- User-friendly dashboard navigation
